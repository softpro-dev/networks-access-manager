# Generate the `.exe` installers (Windows)

Two separate installers, built on Windows x64:

| Installer | Install on | Contains |
|---|---|---|
| `SoftProIt-Network-Admin-<ver>-setup.exe` | Administrators' PCs | Desktop admin app (console window, network scan, "Add My PC") |
| `SoftProIt-Network-Service-<ver>-setup.exe` | Every computer to control | Windows service `OrganizationNetworkAgent` |

## Easiest: double-click

- [build-admin-setup.bat](build-admin-setup.bat) → Admin installer
- [build-service-setup.bat](build-service-setup.bat) → Service installer

Each runs the tests, builds the exe and its installer, then waits for a key press.
Output: `os-apps\installer\Output\`.

## Version

Set `BUILD_VERSION` in `os-apps\.env` (default `1.0.0`):

```env
BUILD_VERSION=1.0.1
```

It sets the installer's version and file name. Increase it for each release so Windows treats
the new installer as an upgrade.

## From PowerShell

```powershell
cd os-apps
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Target Admin -Installer
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Target Service -Installer
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Installer                 # both
# options: -Version 1.0.1 (overrides BUILD_VERSION), -SkipTests
```

Needs 64-bit Python 3.11+ and Inno Setup 6 (`winget install JRSoftware.InnoSetup`).

## Installing

- **Service setup** (run as Administrator) asks for the admin server URL, the organization's
  access token (Organizations → Generate token) and the refresh interval.
  Silent: `setup.exe /VERYSILENT /SERVER=https://admin.example.com /TOKENFILE=C:\secure\token.txt /CACHE=5`
- **Admin setup** (run as Administrator) asks only for the admin server URL and offers a
  desktop icon. Silent: `setup.exe /VERYSILENT /SERVER=https://admin.example.com`

The Service setup upgrades a PC that has the old combined `SoftProIt-Network-<ver>-setup.exe`
installed and removes the admin app that came with it; install the Admin setup separately
where needed.
