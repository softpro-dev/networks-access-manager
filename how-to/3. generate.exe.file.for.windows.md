# Generate the `.exe` installer (Windows)

On Windows x64, after building the executables (`./scripts/build.ps1`):

```powershell
iscc installer\OrganizationNetworkAgent.iss   # needs Inno Setup 6
# → installer\Output\SoftProIt-Network-1.0.0-setup.exe
```

`setup.exe` installs both programs, registers the service, and collects the org settings.
