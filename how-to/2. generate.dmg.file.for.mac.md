# Generate the `.dmg` installer (macOS)

On macOS, after building (`./scripts/build.sh`), wrap the desktop app for drag-install:

```bash
hdiutil create -volname "SoftProIt Network Admin" \
  -srcfolder dist/SoftProIt.network.admin.app \
  -ov -format UDZO dist/SoftProIt.network.admin.dmg
```

The background service installs as a launchd daemon (`.pkg`), not the `.dmg` — see
`installer/README-macos.md`. Signing/notarization needs an Apple Developer ID.
